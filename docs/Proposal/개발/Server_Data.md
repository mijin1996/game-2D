## 1. 목적
**어떤 데이터를 어디에 저장하고, 무엇을 서버가 판정할지** 정하는 문서예요.

## 2. 지금 저장하는 것 (코드 기준)
**아무것도 저장하지 않아요.** 서버도, `PlayerPrefs`도 쓰지 않아요. 최고 점수가 없는 이유예요 (needFix [S-02](../needFix.md)).

## 3. 저장 위치 · 판정 주체 (제안)
| 데이터 | 저장 위치 | 판정 주체 | 이유 |
|---|---|---|---|
| 최고 점수 | 기기 (`PlayerPrefs("BestScore")`) | 클라 | 혼자 보는 기록. 조작돼도 남에게 피해 없음 |
| 소리 설정 | 기기 | 클라 | |
| 출석 · 일일 미션 (Could) | 기기 | 클라 + **기기 시간 조작 방지** | 날짜를 기기 시계로만 보면 시계를 돌려 보상 반복 가능 → 앱인토스 · 서버 시간 사용 검토 |
| 코인 (남는 재화로 만들면) | 기기 → 랭킹 · 판매가 생기면 서버 | 서버 | 돈과 연결되면 조작 방지 필요 |
| 랭킹 (만들면) | 서버 | 서버 검증 | 점수 위조 방지 |

**WebGL(앱인토스)에서 `PlayerPrefs`**
| 확인할 것 | 내용 |
|---|---|
| 저장 위치 | WebGL 빌드의 `PlayerPrefs`는 브라우저 저장소(IndexedDB)에 저장돼요 |
| 지워지는 경우 | 토스 앱 캐시 삭제 · 재설치 시 사라질 수 있음 → 최고 점수가 사라져도 되는지 결정 |
| 저장 시점 | 판이 끝날 때 `PlayerPrefs.Save()`를 바로 부르기 (WebGL은 자동 저장 시점이 늦을 수 있음) |

> 기기를 바꿔도 기록을 남기려면 토스 로그인 · 앱인토스 저장 기능이나 서버가 필요해요 → [F-04](../needFix.md#8-정할-것)

## 4. 외부 연동
| 연동 | 용도 | 실패 시 처리 |
|---|---|---|
| 앱인토스 SDK (`im.toss.apps-in-toss-unity-sdk`) | 배너 · 전면 광고 | 경고 로그만, 게임 진행 (지금 동작) |
| 앱인토스 로딩 화면 (`Assets/AppsInToss/loading.html`) · WebGL 템플릿 (`AITTemplate`) | 미니앱 실행 | — |

## 5. 개발용 패키지 (출시 빌드에서 확인)
`Packages/manifest.json`에 **게임 실행에 필요 없는 개발 도구**가 들어 있어요.

| 패키지 | 용도 | 출시 빌드 |
|---|---|---|
| `com.srcnalt.openai-unity` | 에디터에서 AI 호출 | 제거 또는 에디터 전용 확인 — 빌드에 API 키가 들어가지 않게 |
| `com.coplaydev.coplay` · `com.coplaydev.unity-mcp` | 에디터 자동화 | 에디터 전용 확인 |
| `com.unity.analytics` 3.8.2 | 쓰지 않음 | 정리 ([로그](../기획/Analytics.md)) |
