## 4. 환경 기준 (정할 것 → [F-08](../needFix.md#8-정할-것))
| 항목 | 제안 |
|---|---|
| 실행 환경 | 토스 앱 안 WebGL (Android · iOS 각 1종 이상), itch.io 브라우저 (Chrome · Safari) |
| 목표 FPS | 60 (WebGL), 최소 30 |
| 로딩 시간 | 첫 실행 5초 안 (빌드 용량 · 압축 설정 확인) |
| 화면 | 가로 고정 (`LandscapeMode`), 노치 · 홈 바 영역에 버튼 없음 |
