## 1. 점프 물리 (`player.json`)
```
위 속도     = 힘 × 물리 간격 ÷ 질량 = 600 × 0.02 ÷ 1 = 12
체공 시간   = 2 × 12 ÷ 중력 20 = 1.2초
최고 높이   = 12² ÷ (2 × 20) = 3.6
수평 이동   = 1.2초 × 스크롤 10 = 12
```
| 항목 | 값 | 근거 |
|---|---|---|
| 점프 힘 · 질량 | 600 · 1 | `Main` 씬 `UniRun_Run_0 (1)` (코드 기본값 700) |
| 물리 간격 | 0.02초 (2822399 / 141120000) | `ProjectSettings/TimeManager.asset` |
| 중력 | 20 | `Physics2DSettings` (y = -20), gravityScale 1 |
| 최대 점프 횟수 | 5 | `jumpCnt < 5` |

## 2. 발판 간격 (`platform.json`)
```
발판 시작점 거리 = 생성 간격 × 스크롤 = (1.25 ~ 1.35) × 10 = 12.5 ~ 13.5
빈 틈           = 거리 - 발판 너비 8.41 = 4.1 ~ 5.1
높이 범위       = -3.5 ~ 1 → 높이 차 최대 4.5
```
```
[== A ==]                          [== B ==]
         |<------- 5.1 ------->|          가장 넓은 틈
         |<---------- 12 ---------->|     1회 점프 수평 이동
         |<------------------------------- 60 ---------- ...  5회 점프 최대
```
| 비교 | 값 |
|---|---|
| 가장 넓은 틈 | 5.1 |
| 1회 점프 수평 이동 | 12 (가장 넓은 틈의 약 2.4배) |
| 1회 점프 높이 · 최대 높이 차 | 3.6 · 4.5 |

## 4. 오브젝트 풀 크기
```
spawn #   1   2   3   4   5   6   7   8
type      S   C   C   S   S   C   C   S
S pool    S1          S2  S3          S1   <- 8번째에 S1 재사용
time(s)   0                          8.75  (최소 간격 1.25초 x 7)
```
```
같은 종류 발판의 4번째 사용(= 첫 발판 재사용)이 가장 빨리 오는 경우
bag 순서: [S C] [C S] [S C] [C S] → 달팽이 발판 1, 4, 5, 8번째
→ 8번째 생성 = 7번 간격 × 최소 1.25초 = 8.75초 뒤
→ 그동안 첫 발판은 8.75 × 10 = 87.5 만큼 왼쪽으로 이동한 상태
```
